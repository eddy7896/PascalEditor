  Edit apps/editor/prisma/schema.prisma:

  1. Add two enums (place near existing enums):
     ```prisma
     enum AuditEventType {
       MEMBER_JOINED
       MEMBER_REMOVED
       ROLE_CHANGED
       PROJECT_CREATED
       PROJECT_DELETED
     }

     enum NotificationType {
       SCENE_DUPLICATED
       ADDED_TO_TEAM
       ROLE_CHANGED
     }
     ```

  2. Add TeamAuditLog model:
     ```prisma
     model TeamAuditLog {
       id        String          @id @default(cuid())
       teamId    String
       actorId   String?
       targetId  String?
       event     AuditEventType
       meta      Json            @default("{}")
       createdAt DateTime        @default(now())

       team      Team            @relation(fields: [teamId], references: [id], onDelete: Cascade)

       @@index([teamId, createdAt(sort: Desc)])
       @@index([teamId])
     }
     ```

  3. Add Notification model:
     ```prisma
     model Notification {
       id        String           @id @default(cuid())
       userId    String
       type      NotificationType
       meta      Json             @default("{}")
       readAt    DateTime?
       createdAt DateTime         @default(now())

       user      User             @relation(fields: [userId], references: [id], onDelete: Cascade)

       @@index([userId, createdAt(sort: Desc)])
       @@index([userId, readAt])
     }
     ```

  4. Add back-relations:
     - In `model Team { ... }`: add `auditLogs TeamAuditLog[]`
     - In `model User { ... }`: add `notifications Notification[]`

  Run `pnpm --filter editor prisma generate` then `pnpm --filter editor prisma db push` (or the project's existing prisma command — check apps/editor/package.json scripts first).
