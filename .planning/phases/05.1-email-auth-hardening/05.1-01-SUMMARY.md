## Decisions Made

- **Resend as email provider:** Managed service, reliable delivery, excellent TypeScript DX, free tier sufficient for v1
- **SHA-256 token hashing:** v2 hardening pattern (security, not required for v1 but establishes secure pattern early)
- **Raw token in email, hashed in DB:** Prevents URL leakage if DB is compromised; raw token in email is safe
- **Fire-and-forget email sends:** `.catch()` error logging preserves enumeration safety; timing attacks prevented
- **Email templates in React:** Maintainable, type-safe, easy to test; React Email components mature ecosystem

## User Setup Required

**External services require manual configuration.** Add these environment variables to `apps/editor/.env.local`:

```bash
RESEND_API_KEY=re_xxxxxxxxxxxx                    # Get from Resend Dashboard > API Keys
RESEND_FROM_EMAIL=noreply@yourdomain.com         # Set to a Resend-verified sender address
                                                   # For dev/test without domain: leave unset (defaults to onboarding@resend.dev)
```

To get `RESEND_API_KEY`:
1. Sign up or log in at https://resend.com
2. Navigate to Settings > API Keys
3. Create a new API key
4. Copy the key (format: `re_xxxx...`) into your `.env.local`

For `RESEND_FROM_EMAIL`:
- **Production:** Use a verified sender address (e.g., `noreply@yourdomain.com`)
- **Development/Testing:** Leave unset; defaults to `onboarding@resend.dev` which only delivers to your Resend account email
