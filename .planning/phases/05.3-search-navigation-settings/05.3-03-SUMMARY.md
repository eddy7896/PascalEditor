## Decisions Made
- BreadcrumbProvider scoped to dashboard layout `<main>` — not root layout — keeps it dashboard-only
- setLabel uses functional setState with equality check (`if (prev[key] === label) return prev`) to prevent unnecessary re-renders and potential loops
- BreadcrumbLabelSetter pattern preferred over inline useEffect in server pages — keeps server pages clean and effect logic testable in isolation
- humanize() fallback means settings page (05.3-04) will automatically render "Settings" with zero changes to BreadcrumbNav
