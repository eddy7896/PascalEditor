  <name>Task 1: Create settings server actions (updateUserProfile, changePassword)</name>
  <files>apps/editor/app/dashboard/settings/actions.ts</files>
  <action>
    Create `apps/editor/app/dashboard/settings/actions.ts` with `'use server'` directive at top.

    Imports: `prisma` from `@/lib/prisma`, `getServerSession` from 'next-auth/next', `authOptions` from `@/lib/auth`, `bcrypt` from 'bcryptjs' (verify it is already installed — repo uses bcrypt for credential signup). `revalidatePath` from 'next/cache'.

    Export `updateUserProfile`:
    ```ts
    export async function updateUserProfile(input: { name?: string; image?: string }) { ... }
    ```
    - Get session; resolve userId via `(session?.user as { id?: string })?.id`. Throw 'Unauthorized' if missing.
    - Validate: `name` (if provided) — trim, length 1-80; `image` (if provided) — trim, allow empty string OR must start with `http://` or `https://` and length <= 1024 (basic URL guard, no full URL parser).
    - `prisma.user.update({ where: { id: userId }, data: { name: name?.trim() || null, image: image?.trim() || null } })`. Use `null` when input is explicitly empty string to allow clearing.
    - `revalidatePath('/dashboard')` (so sidebar avatar/name updates).
    - Return `{ success: true }`.

    Export `changePassword`:
    ```ts
    export async function changePassword(input: { currentPassword: string; newPassword: string; confirmPassword: string }) { ... }
    ```
    - Get session + userId; throw if missing.
    - Validate: newPassword === confirmPassword (else throw 'Passwords do not match'). newPassword.length >= 8 (else throw 'Password must be at least 8 characters'). newPassword.length <= 128 (else throw 'Password is too long').
    - `const user = await prisma.user.findUnique({ where: { id: userId } })`. If `!user?.password` throw 'Credential-based login is not enabled for this account' (prevents OAuth-only users from setting a password here in v1; documented limitation).
    - `const ok = await bcrypt.compare(input.currentPassword, user.password)`. If !ok throw 'Current password is incorrect'.
    - `const hash = await bcrypt.hash(input.newPassword, 10)`. Update user with `{ password: hash }`.
    - Return `{ success: true }`.

    Constraints:
    - Both functions must throw plain Error with user-safe messages (no leaking stack/internals).
    - Do NOT log the new password or full bcrypt hash to console.
    - If `bcryptjs` is not in `apps/editor/package.json`, install via `cd apps/editor && bun add bcryptjs && bun add -D @types/bcryptjs` (only if missing — check first with grep).
  </action>

  </verify>
  <done>Both server actions exist, validate inputs, verify current password via bcrypt.compare, hash new password with cost 10, persist via prisma.</done>
