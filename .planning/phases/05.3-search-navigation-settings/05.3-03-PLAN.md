       - Component:
         ```tsx
         export function BreadcrumbNav() {
           const pathname = usePathname();
           const ctx = useContext(BreadcrumbContext);
           const segments = pathname.split('/').filter(Boolean);
           // first segment is 'dashboard' — render as Home link
           ...
         }
         ```
       - Render: `<nav>` with Home link to `/dashboard`. For each segment after `dashboard`, render `<ChevronRight />` separator and then a `<Link href={accumulated}>` with label = `ctx?.labels[segment] ?? humanize(segment)` where `humanize` capitalizes and replaces dashes with spaces. Last segment is non-link `<span>`. Use Tailwind text-zinc-500 / hover:text-zinc-300, text-sm.
       - Hide entirely if segments.length <= 1 (i.e., on /dashboard root).

    3. Create `apps/editor/app/dashboard/_components/BreadcrumbLabelSetter.tsx` ('use client'):
       - Tiny helper: `export function BreadcrumbLabelSetter({ segment, label }: { segment: string; label: string })`.
       - Inside: `const ctx = useContext(BreadcrumbContext); useEffect(() => { if (ctx && label) ctx.setLabel(segment, label); }, [ctx, segment, label]);` — return `null`.
