# Phase 05.2 Plan 02: Soft-Delete Schema + Prisma Extension Summary

**Project soft-delete via deletedAt field + Prisma.defineExtension() intercepting all query operations to auto-exclude archived projects**

## Accomplishments
- Added `deletedAt DateTime?` to Project model; schema validated and Prisma client regenerated
- Created `lib/prisma-soft-delete.ts` exporting `softDeleteExtension` via `Prisma.defineExtension()` — intercepts findUnique, findUniqueOrThrow, findFirst, findFirstOrThrow, findMany, count
- Applied extension in `lib/prisma.ts` via `$extends()` — all imports get filtered client transparently; no call-site changes needed

## Decisions Made
- **findUnique type approach:** Used `(args.where as Record<string, unknown>).deletedAt = null` instead of `AND` wrapping. `ProjectWhereUniqueInput` requires the `id` field to be present at the type level — `AND` breaks the type, spreading deletedAt directly is the correct Prisma pattern.
- **createPrismaClient() wrapper:** Needed for `ReturnType<typeof createPrismaClient>` to correctly type the global cache, since `$extends()` returns a different type than `PrismaClient`.
